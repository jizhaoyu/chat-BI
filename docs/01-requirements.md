# 需求与范围

## 1. 目标用户

- `SYSTEM_ADMIN`：管理平台用户和系统策略。
- `DATA_ADMIN`：注册数据源、同步元数据、配置对象权限和业务术语。
- `ANALYST`：自然语言查询授权数据并保存分析。
- `VIEWER`：查看已分享的只读分析结果。

MVP 采用单租户交付，但核心配置表保留 `tenant_id`，所有数据源、权限和审计查询必须受租户约束。

## 2. MVP 功能

### CBI-F01 身份与权限

- 用户登录与角色校验。
- 数据源、Schema、表、列的授权范围可配置。
- 查询、导出、数据源变更等操作写入审计日志。

### CBI-F02 数据源管理

- 支持 MySQL，完成后扩展 PostgreSQL。
- 保存名称、方言、连接参数密文引用、状态和资源限制。
- 测试连接时验证账号为只读或执行只读探测；无法确认时给出风险提示并禁止启用。
- 连接池设置最大连接数、连接/查询超时和会话级只读属性。

### CBI-F03 元数据与语义层

- 同步授权 Schema 下的表、列、类型、主外键和注释。
- 管理员可配置业务名称、同义词、指标定义、时间字段和敏感等级。
- 元数据拥有版本号，生成 SQL 时记录所用版本。
- 默认只向模型暴露与问题相关且已授权的最小元数据集合。

### CBI-F04 自然语言生成 SQL

- 用户选择数据源并提问，系统先检索相关元数据，再生成结构化候选 SQL。
- 响应展示 SQL、自然语言解释和使用的数据对象。
- 支持先预览 SQL 再执行；MVP 不允许模型绕过确认流程自动执行高成本查询。
- 生成失败时返回可理解的原因，不伪造查询结果。

### CBI-F05 SQL 安全网关

- 解析为 AST，只允许单条 `SELECT` 或经过明确支持的只读 CTE。
- 拒绝 DDL、DML、存储过程、文件操作、危险函数、锁、注释绕过和堆叠语句。
- 校验数据源、Schema、表和列权限；禁止 `SELECT *` 或将其展开为授权列。
- 注入或收紧行数上限；执行前可选用 `EXPLAIN` 做成本检查。
- SQL 方言不受支持或无法完整解析时默认拒绝。

### CBI-F06 受控执行与结果

- 只在只读连接上执行已批准 SQL。
- 限制超时、最大行数、最大响应大小和并发数。
- 对敏感列进行隐藏或脱敏，记录执行耗时、返回行数和错误类别。
- 默认不持久化完整查询结果，只保存安全摘要；用户可在当前会话查看有限结果。

### CBI-F07 解释与可视化

- 基于真实查询结果生成简短数据解释，明确时间范围、单位和空值情况。
- 生成白名单图表规格：表格、指标卡、折线、柱状、饼图中的受支持类型。
- 后端校验维度、指标字段和数据类型，不执行模型生成的脚本。

### CBI-F08 反馈与评测

- 用户可标记 SQL/答案正确与否并提交修正 SQL。
- 固定评测集记录问题、授权上下文、期望 SQL 或期望结果摘要。
- 至少评估执行正确率、对象命中率、安全拒绝率和响应时间。

## 3. 非功能要求

- 安全：真实只读凭据、密钥加密、对象级授权、SQL AST 白名单、结果脱敏和审计。
- 资源隔离：平台库与分析库连接池隔离，每个数据源拥有并发和超时预算。
- 可靠性：元数据同步可重试；模型失败不触发数据库执行；执行错误分类可追踪。
- 性能：元数据检索 P95 小于 300 ms；查询耗时由数据源预算约束并明确展示。
- 可观测性：记录生成、验证、解释和执行的分段耗时，统计拒绝原因和数据源健康度。

## 4. 暂不实现

- INSERT、UPDATE、DELETE、DDL 或任何数据库写回。
- 自动修复生产数据或自动创建索引。
- 跨多个数据源的联邦查询。
- 任意 SQL 方言；只实现并测试明确列出的方言子集。
- 任意 Python/JavaScript 执行和模型生成的可执行图表代码。
- 面向海量数据的完整 BI 数仓和 OLAP 引擎替代品。

## 5. 成功标准

- 新开发者可启动样例数据源并完成“同步元数据、提问、审核 SQL、执行、查看图表”的闭环。
- 任何写操作、越权对象或超出资源限制的 SQL 都无法到达数据库执行器。
- 评测集可证明安全规则没有以明显牺牲正常查询为代价。
- 查询全过程可关联问题、提示版本、元数据版本、SQL、规则决策和执行指标。
