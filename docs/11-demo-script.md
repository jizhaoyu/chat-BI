# 演示脚本

本文档用于约束作品集演示闭环。每个阶段完成后，都应尽量让演示脚本中的对应步骤可运行。

## 1. 管理员准备

1. 启动 Docker Compose，包含平台 MySQL 和样例销售 MySQL。
2. 使用 `DATA_ADMIN` 登录。
3. 创建样例销售数据源。
4. 测试连接，系统证明账号只读。
5. 同步元数据，生成活动快照。
6. 配置业务术语：销售额、订单数、客单价、地区、门店、品类。
7. 配置敏感字段：手机号、邮箱、成本价。
8. 给分析用户授权销售事实表、门店、地区和商品部分字段。

## 2. 正常分析路径

1. 使用 `ANALYST` 登录。
2. 创建分析会话。
3. 提问：“最近 30 天各地区销售额是多少？”
4. 系统返回候选 SQL、解释和引用对象。
5. 用户点击校验，系统签发短时 `approvalId`。
6. 用户执行查询。
7. 系统返回有限结果集、截断标记、解释和柱状图规格。
8. 审计页面展示同一次请求的生成、校验和执行链路。

## 3. 安全拒绝路径

1. 提问：“展示每个商品的成本价和利润。”
2. 系统生成候选或用户提交修正 SQL。
3. SQL 网关识别 `cost_price` 未授权。
4. 系统拒绝执行，返回 `SQL_OBJECT_FORBIDDEN` 或同类稳定错误码。
5. 审计记录拒绝原因，但不向普通用户泄露额外敏感字段信息。

## 4. 注入防护路径

1. 提问：“查询销售额；DROP TABLE fact_order。”
2. SQL 网关拒绝多语句或禁止语句。
3. 执行器没有收到任何裸 SQL。
4. 样例分析库结构保持不变。

## 5. 资源治理路径

1. 提交无 `LIMIT` 的大结果查询。
2. SQL 网关注入默认行数上限。
3. 执行器按数据源策略限制超时、行数和响应大小。
4. 返回结果包含 `truncated=true` 或资源限制错误。

## 6. 面试讲解重点

- 为什么模型输出不能直接执行。
- 为什么只读账号和 SQL AST 网关都需要。
- 如何保证 approvalId 不能被重放或换 SQL。
- 如何证明平台库和分析库凭据隔离。
- 如何用评测集同时衡量正确率和安全拒绝率。
