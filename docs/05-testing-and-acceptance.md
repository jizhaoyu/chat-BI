# 测试与验收

## 1. 测试层次

- 单元测试：AST 规则、权限匹配、脱敏、资源策略、状态机和图表 Schema。
- 属性/参数化测试：不同空白、大小写、注释、嵌套、CTE、子查询和函数组合。
- 集成测试：Testcontainers 启动平台 MySQL 与独立分析 MySQL，验证真实权限和超时。
- 契约测试：模型候选使用固定 Fake；真实模型测试单独标记且设置预算。
- E2E：自然语言问题到安全执行、结果解释和审计的完整路径。
- 性能与故障测试：慢查询、连接池耗尽、取消、数据源下线和元数据变化。

## 2. SQL 安全回归集

至少覆盖：

- 合法的简单聚合、分组、排序、JOIN、子查询和受支持 CTE。
- `INSERT/UPDATE/DELETE/TRUNCATE/DROP/ALTER/CREATE/CALL`。
- 多语句、注释混淆、大小写/Unicode 空白变体和解析失败输入。
- 越权 Schema、表、列以及通过别名或子查询间接引用。
- `SELECT *`、危险函数、文件读写、锁和超大 `LIMIT`。
- 超深嵌套、笛卡尔积、高成本全表扫描和超时查询。
- 批准后 SQL、用户、权限、元数据版本或参数被替换。

无法确定安全性的语法默认拒绝，并返回稳定错误码。

具体 SQL 白名单、禁用语法、对象解析和 `ApprovedQuery` 约束见 `docs/06-sql-guard-policy.md`。新增规则时必须同步增加允许用例和拒绝用例。

## 3. 数据源与隐私测试

- 样例只读账号执行写操作由数据库拒绝。
- 平台数据库凭据无法连接外部业务库，反之亦然。
- 数据源密码读取接口、日志和错误响应均不可见。
- 未授权用户无法查看元数据、候选 SQL、结果或审计详情。
- 敏感列按配置隐藏/脱敏，导出和图表路径同样生效。

## 4. AI 与图表测试

- 模型返回非法 JSON、空 SQL、多 SQL 或幻觉字段时被安全处理。
- 模型指示跳过校验时不能影响执行管线。
- 解释必须依据实际结果，不把截断结果描述成全部数据。
- 图表字段必须存在于结果 Schema，类型和图表类型匹配。
- 图表配置拒绝脚本、HTML、外部 URL 和未知属性。

## 5. MVP 验收清单

- [ ] `mvn verify` 全部通过。
- [ ] Docker Compose 可启动平台库和样例分析库。
- [ ] 样例销售数据集和黄金问题可重复初始化。
- [ ] 样例分析账号经负向测试证明不能写入。
- [ ] 元数据同步、版本切换和权限过滤正确。
- [ ] 合法 SQL 通过，禁止语句和越权对象无法到达执行器。
- [ ] 超时、最大行数、并发和结果大小限制生效。
- [ ] 固定自然语言问题生成正确或可纠正的候选 SQL。
- [ ] 查询结果、解释、图表和审计能够关联同一次执行。
- [ ] 评测输出执行正确率、安全拒绝率和误拒率。
- [ ] README 明确支持方言、语法子集和已知限制。
- [ ] 演示脚本中的正常路径、安全拒绝路径、注入防护路径和资源治理路径可复现。

## 6. 完成声明规则

不能以模型生成了一条看似正确的 SQL 宣称功能完成。必须证明 SQL 使用授权对象、经过规则批准、在只读连接受限执行，且结果与预期数据一致。
